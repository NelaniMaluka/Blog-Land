# BlogLand
A full-stack blogging platform with rich features — built with React (frontend) and Spring Boot (backend).

BlogLand is a modern blogging platform that allows users to create, read, update, and delete posts, manage accounts, and interact with content.  
This project is organized into two repositories:  

- **Frontend**: React-based web client  
- **Backend**: Spring Boot REST API  

### Repositories
- [BlogLand Frontend](./blog-land-frontend)
- [BlogLand Backend](./blog-land-backend)

### Features
- User authentication & authorization  
- Create, edit, and delete blog posts  
- Commenting system  
- Responsive UI with modern design  
- Secure backend API with JWT authentication  

### Tech Stack
- **Frontend:** React, Redux, TailwindCSS  
- **Backend:** Spring Boot, Spring Security, JPA, MySQL  

### Setup
Each repo contains its own setup instructions.  

1. Clone this repository  
2. Navigate to the desired repo (frontend or backend)  
3. Follow the installation guide in that repo's README
